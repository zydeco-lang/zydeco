# 2026-09-02 — Type Lint: Well-Formedness Pass

Worklog for the well-formedness pass of
[`docs/proposals/tyck-lint.md`](../proposals/tyck-lint.md).
The proposal is the stable design account; this log records how the first corpus run
forced three invariant corrections and what the mutation tests proved.

## What landed

- `lang/statics/src/validate/lint.rs`: `LintChecker` with ten check groups —
  fill closure, annotation presence, annotation sorts, paired annotations
  (root plus `term_facts`), and reference existence for kinds, types, values,
  computations, patterns, and the auxiliary tables.
- `TermFacts::annotation()` accessor in `lang/statics/src/arena.rs` (the field
  was module-private and the validator needs to iterate all facts).
- Gate: `CommandCompiler::with_lint_types` in `cli/src/compile.rs`, exposed as
  the global `--lint-types` CLI flag. Lint failures abort with an internal
  error report; the pass runs outside the salsa query graph so memoized checks
  are never perturbed.
- Test harness: `SourceCase::check_linted` and `SourceCase::checked_arena` in
  `lang/tests/src/lib.rs`; mutation tests in
  `lang/tests/tests/tyck_lint.rs`.

## Corpus run: three invariant corrections

The first arena-wide run over every `.zy` file under `lib/` fired 217–220 errors
per program, all in two shapes. Each shape was the lint asserting an invariant
the checker does not maintain, not a checker bug:

1. `KindDisagreement` (249 findings across the corpus).
   `reconcile_k` (`lang/statics/src/check/mod.rs`, the `TermAnnId::Type` arm)
   deliberately discards the synthesized kind of a pair and records the
   least-upper-bound result instead, so the pair's kind is a different
   `KindId` than the type node's co-located kind.
   Comparing normalized forms was not enough either: `Kind`'s derived equality
   still compares leaves by identifier, and `VType`/`CType` leaves are *not*
   canonicalized across the arena. The remaining "disagreement" after switching
   to normalized comparison was `Arrow(VType, CType)` against
   `Arrow(VType, CType)` with different leaf ids.
   Fix: a recursive `kinds_agree` that resolves every leaf through
   `normalized_kind_at` before comparing constructor tags.

2. `MissingAnnotation` on `AbstId` (46 findings).
   Recursive-group identities (`lang/statics/src/check/mod.rs`, around the
   `rec_group_abst_judgment_at` call) allocate witnesses and denote them with a
   `Type::Abst` node whose *co-located kind* carries the classifier; no
   `annotations_abst` row is written. Arena-wide witness-annotation presence is
   not an invariant. Fix: drop the check; witness kinds will be derived
   structurally in the re-derivation pass.

3. `ResidualHoleValue` (2 findings, both FFI files).
   A checked foreign import materializes its external value as a typed
   `Value::Hole` placeholder, with `foreign_imports` mapping the node to its
   marshalling plan. Fix: a hole term node is legitimate exactly when it has a
   `foreign_imports` row.

After the corrections, the entire corpus lints clean with zero findings.

## Observations for the Re-Derivation Pass

- No `Type::Var` node survives in the finished arenas of definition-heavy
  programs: bound type variables are referenced through `AbstId` witnesses
  (`TypeAbstraction`'s "body refers to its binder through an abstract
  witness"), and definition-backed variables are substituted during
  normalization. The re-derivation pass's kind synthesis may treat a surviving
  `Var` as an immediate finding; recorded as an open question in the proposal.
- `annotations_value`/`annotations_compu` are complete arena-wide, including
  elaboration-generated nodes — the fourth open question in the proposal is
  answered affirmatively for the well-formedness pass.
- The mutation-test fixture initially used an annotation-free `fn` parameter,
  which the checker rejects with `MissingSolution` when the definition is
  checked before its use site; the final fixture combines a data declaration,
  an inference thunk (`{ fn value => ret (value, value) }`, solved from the
  body), and an existential type to guarantee fills, value-variable
  references, and package-shaped types in one program.

## Mutation-test ledger

Seven tests, one per corruption family; each first proves the fixture lints
clean, then corrupts one fact in a cloned arena:

| Test | Seeded corruption | Expected finding |
| --- | --- | --- |
| `clean_programs_pass_the_gated_check` | none (gated path) | silence |
| `removing_a_value_annotation_is_reported` | drop `annotations_value` row | `MissingAnnotation` |
| `crossing_annotation_sorts_is_reported` | value row → `CType`-kinded type | `AnnotationSort` |
| `reintroducing_a_type_hole_is_reported` | type cell → `Fillable::Fill` | `UnfilledType` |
| `dropping_a_variable_annotation_is_reported` | drop `annotations_var` row of a used def | `UnresolvedDef` |
| `desynchronizing_the_root_annotation_is_reported` | root node's row → other type | `AnnotationDisagreement` |
| `turning_a_value_into_a_hole_is_reported` | value node → `Value::Hole` | `ResidualHoleValue` |

All seven pass. `DanglingReference` has no dedicated mutation yet: removing a
node requires a `remove` on `ArenaSparse`, which the container does not expose,
and fabricating identifiers is not possible through the public arena API. The
variant is still exercised indirectly whenever a reference target loses its
annotation row.

## 2026-09-02, second session: re-derivation pass

The re-derivation pass landed in `lang/statics/src/validate/rederive.rs` (kind re-derivation,
constructor-shape judgments, witness scope checking) and is wired into the same
`--lint-types` gate. The corpus run was a long negotiation; the durable lessons:

1. **The canonical scoping account is `docs/proposals/term.md`, not the checker's
   own README.** There is no top level: a file is one term, and `begin` blocks
   dependency-order mobile (`that`) bindings into ordinary telescopes. The
   elaborated term obeys strict lexical scope. An early draft treated the root
   as a recursive binding group and widened binder scopes for bindees; that was
   wrong and was reverted once the canonical account was read.
2. **Named witnesses are ambient.** Recursive type components allocate identities
   together (they appear as `abst_hints` rows, with or without `annotations_abst`
   entries), and package openings bind witnesses through the elaborated program.
   The arena observable for most of them is the hint row.
3. **Equality-with-node judgments cannot fire on this artifact.** A shared node
   used at several instantiations of an enclosing universal, or inside a package
   member elaborated per import, carries one annotation; the recording sites
   legitimately disagree (generic versus instantiated, labeled versus plain).
   Every such judgment — tail agreement, abstraction codomains, application and
   projection results, pattern-versus-domain — was retired. Constructor shapes
   (`Thk`, `Ret`, named, unit, literal) are instantiation-stable and judge,
   guarded to operands free of abstract identities and non-constructor
   applications. Products were retired last: composite operands multiply the
   same sensitivity.
4. **Definition scoping is deferred.** References cross import and alias
   boundaries ("repeated imports share that root"); the arena records no
   per-reference binding context. Existence stays the well-formedness pass's check.

Mutation coverage grew to eight tests, adding a thunk-shape desynchronization
that the re-derivation shape judgment catches. The whole `lib/` corpus passes
`zydeco check --lint-types` with zero findings.
