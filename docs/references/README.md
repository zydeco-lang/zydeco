# References

These concise references assume basic programming-languages background.
The language reference gives source rules and observable behavior; the compiler reference follows their implementation.

- [Language reference](language.md): syntax, typing, evaluation, static composition, packages, host interfaces,
  and execution profiles.
- [Compiler implementation reference](compiler.md): phase contracts, representations, checking, lowering,
  runtimes, tooling, and validation, with entry points and maintenance indexes.

The references own material transferred
through the [completed consolidations](../todos/reference-plan.md#completed-proposal-retirements).
Remaining proposals retain independent rationale and design questions; component guides locate local modules.
[Documentation todos](../todos/README.md) hold drift, deferred designs, and remaining migration work.

Use the [tutorial](../tutorial/zydeco-guide.md) for an introduction, the [library guide](../../lib/std/README.md)
for API inventories, and [CONTRIBUTING](../../CONTRIBUTING.md) for commands and development workflows.
