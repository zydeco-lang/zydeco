# References

The references serve readers with basic programming-languages background.
The language reference gives source rules and observable behavior; the compiler reference follows their implementation.

- [Language reference](language.md): a concise draft covering syntax, typing, evaluation,
  static composition, packages, host interfaces, and execution profiles.
- [Compiler implementation reference](compiler.md): an outline covering phase contracts, representations,
  checking, lowering, runtimes, tooling, and validation.

The language draft is under review.
Existing [DESIGN](../../DESIGN.md) sections and owning proposals retain their authority until consolidation is approved.
[Documentation todos](../todos/README.md) hold the drift list and migration plan.

Use the [tutorial](../tutorial/zydeco-guide.md) for an introduction, the [library guide](../../lib/std/README.md)
for API inventories, and [CONTRIBUTING](../../CONTRIBUTING.md) for commands and development workflows.
