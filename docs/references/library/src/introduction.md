# Zydeco Standard Library Reference

This reference specifies the canonical contracts of Zydeco's standard library modules:
module organization, relative monads and effect transformers, and manual memory, layouts, views, and byte buffers.
These abstractions are implemented in ordinary Zydeco over the primitives and capabilities defined
in the [language reference](../../language/src/introduction.md).

Use the [standard library guide](../../../../lib/std/README.md) for API inventories, usage recipes,
and example walkthroughs, the [compiler implementation reference](../../compiler/src/introduction.md) for runtime
and lowering mechanics, and the [rule ownership map](../../README.md#rule-ownership) to trace contracts
across all three references.
