# Zydeco Language Reference

This reference describes the current source language and its execution boundaries.
It assumes basic familiarity with typed lambda calculi, polymorphism, and operational semantics.
The [language guide](../../../tutorial/zydeco-guide.md) provides a longer introduction,
the [compiler implementation reference](../../compiler/src/introduction.md) documents the phase representations
and algorithms implementing these rules, the [rule ownership map](../../README.md#rule-ownership) connects source
and implementation contracts, and [CONTRIBUTING](../../../../CONTRIBUTING.md) covers command-line workflows.
